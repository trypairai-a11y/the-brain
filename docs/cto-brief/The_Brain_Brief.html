The Brain

An agent with no memory treats every conversation as the first. The Brain closes the loop, in four stages.

The knowledge loop

|Architecture
The Brain

A pnpm monorepo: a Fastify API in front of Postgres, a React dashboard, a prompts package. Deliberately conventional, so the interesting parts stay legible.

System topology

One catchall on Vercel

Bracket files match a single path segment, so all routing re-injects into the full Fastify app through api/v1/catchall.ts.

Redis is optional

The cache client stubs to no-ops when unset and fails fast when down. The system runs correctly with no Redis at all.

Contract defined once

packages/shared holds the Zod schemas used by both API and web, so the data contract is written in exactly one place.

External keys parked

Anthropic, OpenAI, SMTP, and R2 carry placeholders. The features needing them are deferred, not broken.

What every call passes through

1 Auth

tb_live_ keys hit a SHA-256 lookup with revocation and expiry. Otherwise JWT.

2 Scope

read, write, or admin. Agent keys never reach admin. A 403 names the missing scope.

3 Validate + tenancy

Zod checks params, then the handler runs inside the tenant transaction with RLS active.

4 Audit

Every write and admin call writes an audit_log row, payloads truncated to counts.

|Security
The Brain

Tenant isolation lives in the database, not in application code. Defense in depth, from the edge to the row.

Edge. Helmet CSP and HSTS, per-route rate limits, constant-time login throttle.
Auth. JWT for users, tb_live_ keys for agents, SHA-256 hashed, least-privilege.
Validation + tenancy. Zod on every handler, FORCE ROW LEVEL SECURITY on every table, no BYPASSRLS.
Audit. Every write and admin call logged with operation name and truncated params.
a buggy query cannot see another tenant's rows

|Handoff
The Brain

The system runs on our own stack, git-connected and auto-deploying. Picking it up is a short list.

1
Push to main to ship, no CLI ritual
2
Steps to wire an agent: load resolver, hand it a key
0

To pick it up

  1. Clone trypairai-a11y/the-brain, run pnpm dev for the full loop locally against embedded Postgres on port 55433.
  2. To ship, push to main. Vercel auto-builds and deploys to brain-flare.vercel.app. Neon Postgres sits in Frankfurt.
  3. To wire FAI, load skills/RESOLVER.md into its system prompt and hand it a scoped tb_live_ key. The skills already point at production.
  4. First, rotate the seeded admin credentials. Then embeddings behind the query operation.
Two-layer design A machine-checkable operations contract underneath, human-readable skills on top. The agent's behavior is reviewed in a pull request, not buried in code.
Two latent bugs found and fixed Arabic POST bodies were 400-ing through the Vercel catchall (stale content-length on multibyte text). A Redis outage could starve the 5-second transaction. Both fixed on main.
